# Network Pulse Analyzer v2.0

The v2.0 branch turns Network Pulse from a visual analytics demo into an evidence first biological discovery surface.

## New v2 surfaces

1. Discovery
   Adversarial multi perspective hypothesis generation with explicit support, contradiction, novelty and experiment design.

2. Evidence
   Claim lineage and provenance objects inspired by ALCOA+ style data integrity thinking.

3. Simulate
   Deterministic node removal and local topology perturbation before any interpretation layer is applied.

## Core architectural rule

Reasoning systems may interpret biology, but deterministic code owns calculations, topology, filtering, identifiers and provenance.

## Routes

/discovery
/evidence
/simulate

## Foundation added in this branch

src/lib/discoveryEngine.ts contains reusable deterministic primitives for degree analysis, influence ranking, pathway signal scoring, evidence bundle generation and counterfactual node removal.

src/test/discoveryEngine.test.ts verifies the deterministic layer.

## Direction

The current branch intentionally keeps the original frontend only architecture so it remains easy to run. The next production step is a backend service for literature retrieval, model orchestration, signed run manifests, persisted evidence graphs and real scientific tool integrations.
